# 画笔勇者：25 次冒险

原创像素风的专属绘画成长网站，主角为持魔法画笔的女勇者。核心功能聚焦 P0，五个章节采用独立地形、路线和地标，并支持角色待机、环境变化、宝箱和信件动画。

地图更新：初始草原保留村庄、风车与心愿湖；迷雾森林使用古树、树屋、溪流木桥和发光蘑菇；古代遗迹使用砂岩断崖、断柱、星盘和符文石门；雪山试炼使用连绵雪峰、峡谷吊桥、暖炉营地和灯塔；最终城堡为彩窗、立柱、红毯和作品画框组成的室内画廊。后四章不再复用草原的小屋、风车和湖泊。

## 当前本地版本

本仓库保存当前最新工程源码。GitHub 备份与网站发布分开进行；线上 Sites 版本维持上次发布状态，待用户确认后再同步。

1. 打开首页即可访问同一份共享冒险，上传、查看、编辑作品、开启宝箱和阅读已解锁来信，无需 ChatGPT 账号。
2. 管理入口为页脚“冒险发起人入口”或 /admin，使用独立管理密码。可以编辑标题、正文、1–25 解锁节点，保存草稿、发布或撤回为草稿。
3. 未开启宝箱金额在接口中为 null；前端不包含奖励金额配置，不显示总奖金额或未开启奖励的累计值。已解锁但未开启时仍保密。
4. 在服务端配置 QUEST_ADMIN_PASSWORD（16–256 字符，建议随机强密码）。本地配置保存在已忽略的 .dev.vars；不应复制本地测试密码到生产。
5. 前两张历史原图仍可由管理员导入。没有原图时从零开始，不用示例作品冒充真实进度。

所有访客操作同一份共享进度。普通访客不能编辑信件、记录发放或导出管理备份；草稿和未解锁正文不会通过公开接口返回。旧账号记录保留，应用不再依赖它们授权。

## 已实现

- 无账号共享冒险，独立管理密码与服务端权限检查。
- 25 个唯一作品节点，JPG / PNG / WebP 上传、预览、取消、图片签名和 10 MB 限制。
- 新冒险默认只展示图片上传和一条小贴士；自由记录默认折叠、可完全跳过，名称和日期自动填写，之后可在作品编辑中补充。历史导入保留原始日期要求。
- 作品真实保存至私有 R2；元数据和进度保存在 D1。
- 原始创作日期、名称、心情、备注；编辑与替换不增加进度。
- 只删除最后一张作品，二次确认，历史奖励永久保留。
- 五章节像素地图、女勇者、路线节点、下一节点入口、章节切换、全路线。
- JRPG 冒险指令栏、女勇者档案、羊皮纸对话和五种场景的前景层次；本地中文像素字体及其授权文件。
- 终章之约截止于北京时间 2026 年 11 月 7 日全天结束，实时倒计时；最后 7 天及 24 小时加强提示，完成 25 幅后显示达成状态，到期仍可继续冒险。
- 25 格图鉴、鼠标/键盘聚焦放大预览、手机点击大图、缩放、前后切换。
- 任意两幅作品并排成长对比、交换作品、同步缩放，不裁切原图比例。
- 六阶段固定奖励，开启前保密，开启后揭晓；金额仅保存于服务端数据。
- 独立记录首次解锁、开启、实际发放时间和备注。只有管理员能标记实际发放。
- 默认与自定义信件、草稿、发布、按节点解锁、阅读状态、重复阅读。
- 第 25 张通关判定、最终宝箱和基础通关庆祝；禁止第 26 张上传。
- 减少动画、默认关闭的原创合成音效、手机布局。
- 管理员元数据 JSON 导出；单张原图下载。

## 工程

React 19 + TypeScript + Vinext + Cloudflare Workers / D1 / R2。普通冒险无需登录，管理入口使用 HttpOnly / SameSite=Strict 签名 cookie（HTTPS 下启用 Secure 和 __Host- 前缀）。会话有效期 8 小时，更换管理密码会令旧会话失效。登录具有持久化的失败次数限制。未新增第三方认证依赖。

- `components/`：页面、原创像素地图与人物、上传、图鉴/对比、管理员。
- `lib/quest.ts`：公开章节/宝箱节点、类型、日期与图片校验。
- `lib/admin-auth.ts`：独立密码校验、签名管理会话。
- `lib/server.ts`：权限、作品、奖励、信件接口。
- `app/api/quest/[...path]/route.ts`：有大小上限的请求读取与 API 路由。
- `db/schema.ts`、`drizzle/`：模型及生成的数据库迁移。
- `styles/quest.css`、`styles/jrpg.css`、`styles/tokens.css`：基础样式、JRPG 外观、响应式布局与设计变量。
- `components/ChapterScenery.tsx`、`components/PixelWorld.tsx`：五套差异化场景、地图前景和女勇者。
- `components/QuestCountdown.tsx`：终章倒计时界面，日期与阶段逻辑在 `lib/quest.ts`。
- `public/fonts/`：本地字体及开源授权；演示画作和运行产生的测试数据不纳入 GitHub 源码。
- `.openai/hosting.json`：Sites 项目标识和云存储绑定。
- `.env.example`：可选本地环境说明，无密钥。

## 本地运行

需要 Node.js 22.13+ 和 pnpm 11.25.0。在已忽略的 `.dev.vars` 中自行配置 `QUEST_ADMIN_PASSWORD`；不要提交密码。仓库不含实际密码、数据库、上传作品或本机测试进度。

```sh
pnpm install --frozen-lockfile
pnpm build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_reflective_steve_rogers.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_public_adventure_admin.sql
pnpm dev
```

以上迁移命令只适用于全新数据库；已有旧版本仅应用新增的 0001 迁移一次。当前本机迁移已完成并保留备份，之后直接 `pnpm dev`。访问终端给出的回环地址（通常为 `http://127.0.0.1:5173`），管理入口为 `/admin`。本地数据与线上隔离。

源码更新后可用 `pnpm build`、`pnpm start` 预览正式 Worker。构建预览不模拟登录。

## 数据与奖励一致性

图片先写入 R2，再通过 D1 批量事务写入作品并解锁奖励。一个节点只有一幅作品，一个请求 ID 只保存一次，奖励按节点唯一。保存失败时不推进进度；替换不生成新奖励；删除只允许末尾节点且不删除奖励历史。开启宝箱只表示已开启，实际发放是管理员在网站外转账后的独立操作。
